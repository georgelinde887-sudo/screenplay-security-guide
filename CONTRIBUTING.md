# Contributing to the Screenplay Security Guide

Thank you for your interest in improving this open-source resource on screenplay security, confidential document distribution, and entertainment production workflows.

We welcome thoughtful contributions that enhance the technical depth, practical utility, and clarity of these guides for screenwriters, producers, directors, and film production teams.

---

## Areas Where Contributions Are Welcomed

1. **Practical Production Workflows**: Real-world field practices for sharing scripts during pre-production, casting, table reads, executive review, and financier packaging.
2. **Technical Corrections & Clarifications**: Keeping document security explanations technically precise (e.g., browser sandboxing, PDF rendering limitations, font-embedding risks, watermarking persistence).
3. **Accessibility Improvements**: Enhancing readability, diagram descriptions, and alt text for screen readers.
4. **Legal & NDA Gating Context**: Jurisdictional nuances, best practices for non-disclosure agreement presentation, and chain-of-title recordkeeping considerations.
5. **Security Checklists**: Additional operational checklists for indie productions, studio lots, and remote writers' rooms.

---

## Contribution Guidelines

To maintain the integrity and educational value of this repository:

- **No Promotional Spam or Keyword Stuffing**: Contributions must provide genuine educational or procedural value. Pull requests adding low-quality external backlinks, keyword dumps, or unsolicited commercial pitches will be closed immediately.
- **Maintain Clear, Professional Language**: Write in direct, technical, and objective language. Avoid hyperbolic buzzwords ("unhackable", "bulletproof", "revolutionary").
- **Preserve Privacy Standards**: Never submit screenshots or logs containing real personal email addresses, production phone numbers, real unreleased script pages, or active IP addresses. All demonstration material must use synthetic or RFC-compliant dummy values (e.g., `@example.com`, `192.0.2.x`).
- **Respect Copyright & Confidentiality**: Do not upload actual copyrighted screenplays from active productions or other authors. Only use fictional demonstration scripts specifically released under open or non-commercial licenses.

---

## How to Submit Changes

1. **Fork the Repository**: Create your branch from `main`.
2. **Make Surgical Edits**: Modify only the relevant guide, checklist, or documentation file.
3. **Validate Markdown & Links**: Ensure all relative links, image paths, and formatting render properly.
4. **Open a Pull Request**: Provide a concise description of what you improved, why it helps entertainment teams, and any relevant references.

---

## Code of Conduct

All contributors and maintainers are expected to interact professionally, respectfully, and constructively.
